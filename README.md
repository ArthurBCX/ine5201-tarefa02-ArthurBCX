# Calculadora com interface gráfica

Aplicação de calculadora em Python com interface feita usando FreeSimpleGUI. Ela
permite realizar operações de adição, subtração, multiplicação e divisão, inserir
números decimais, apagar o último dígito e consultar os cinco cálculos recentes.
A tecla `C` limpa o display, a operação pendente e o histórico.

## Requisitos

- Python 3
- FreeSimpleGUI

Instale a dependência com:

```bash
python -m pip install FreeSimpleGUI
```

## Como executar

Na pasta do projeto, execute:

```bash
python calculadora_gui.py
```

Use os botões da janela para inserir os números e operações. Pressione `=` para
calcular, `←` para apagar o último caractere e `C` para limpar a calculadora e o
histórico.
